## تفاصيل القرارات الحرجة

### D4/D5/D6 — نموذج التعرّف على الوجه
| العنصر | القيمة |
|---|---|
| كشف الوجه | `google_mlkit_face_detection` (يعمل على الجهاز، مجاني) |
| استخراج السمات | **MobileFaceNet** بصيغة TFLite — 128 بُعداً، مدخل 112×112 |
| نموذج السمات | `app/assets/models/mobilefacenet.tflite` (Apache-2.0) |
| كشف الحيوية | `app/assets/models/liveness_antispoof.tflite` (MIT) |
| التشغيل | محلي 100% — لا إرسال صور عبر الشبكة |
| المعالجة | `(px - 127.5) / 128` ثم تطبيع L2، ومطابقة بالتشابه الجيبي |
| العتبة الافتراضية | 0.45 (قابلة للضبط) — وهامش فصل بين أفضل تطابقين |

### D9 — عزل المدارس
- كل جدول يحمل `school_id`.
- في PostgreSQL: سياسات **RLS** تفرض العزل على مستوى قاعدة البيانات:
  `current_setting('app.current_school_id')`.
- لا يستطيع أي استعلام (حتى لو أخطأ الكود) رؤية بيانات مدرسة أخرى.

### D10 — حساب المالك الثابت
- جدول مستقل `platform_admins` (ليس مرتبطاً بمدرسة).
- يدير: إنشاء/تعطيل المدارس، حسابات مسؤولي النظام، إعدادات المنصة، النسخ الاحتياطي.
- كلمة المرور تُخزَّن Argon2id فقط، وتُنشأ عبر سكربت تهيئة (لا أسرار في الكود).

### D11 — الواجهات
مبدأ التصميم: **بساطة قصوى**.
- قائمة جانبية قصيرة (5–7 عناصر كحد أقصى لكل دور).
- لا مصطلحات تقنية، أزرار واضحة، رسائل بالعربية.
- شاشة الحضور مختلفة تماماً: تكبير + نتيجة كبيرة + بلا تفاعل يدوي.
