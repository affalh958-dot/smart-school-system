# دليل البناء والتشغيل

## المتطلبات
| الأداة | الإصدار |
|---|---|
| Flutter | 3.47.7 (stable) أو أحدث |
| Dart | 3.13.5+ |
| JDK | 17 أو 21 |
| Android SDK | platform 36 + build-tools 36 |
| NDK | 28c (يلزمه tflite_flutter) |

## أندرويد (تطبيق الحضور)
```bash
cd app
flutter pub get
flutter build apk --release          # ملف APK للتثبيت
# أو نسخة للاختبار:
flutter build apk --debug
```
الملف الناتج: `app/build/app/outputs/flutter-apk/app-release.apk`

التثبيت على الجهاز:
```bash
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

## الحاسوب (برنامج ويندوز/سطح المكتب)
```bash
cd app
flutter build windows --release      # على ويندوز
# على لينكس للاختبار:
flutter build linux --release
```

> نفس كود المشروع نفسه (Flutter) يبني **تطبيق الهاتف (Android) وتطبيق الحاسوب** — لا نسختين منفصلتين ولا WebView.

### تشغيل برنامج الحاسوب المُثبَّت (ويندوز)
- **المثبّت:** شغّل `SmartSchool-Setup.exe` → يثبّت ويُنشئ اختصاراً على سطح المكتب.
- **المحمول:** فك `SmartSchool-Windows-portable.zip` → شغّل `school_app.exe` (اترك مجلد `data` وملفات `dll` بجانبه).
- إن ظهر تحذير SmartScreen: «مزيد من المعلومات» → «التشغيل على أي حال» (الملف غير موقّع رقمياً).
- إن لم يفتح: راجع `%APPDATA%\school_app\school_crash.log` (يُسجّل كل خطأ بدء تشغيل).

### تشغيل سطح المكتب على لينكس (مُتحقَّق منه)
```bash
sudo apt-get install -y libsecret-1-dev libjsoncpp-dev libcurl4-openssl-dev \
  libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev
cd app && flutter build linux --release
./build/linux/x64/release/bundle/school_app     # (على شاشة سطح مكتب، أو عبر xvfb-run للاختبار)
```
الناتج مُتحقَّق منه فعلياً: التطبيق يعمل ويبني قاعدة البيانات دون أخطاء (سجل الأخطاء فارغ).

- كل النماذج والأصول مضمّنة داخل التطبيق (`assets/models`, `assets/db`) — **لا تحميل من الإنترنت عند التشغيل**.
