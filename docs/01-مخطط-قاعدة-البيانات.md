# مخطط قاعدة البيانات — نظام إدارة المدرسة الذكي

| البند | القيمة |
|---|---|
| قاعدة البيانات | PostgreSQL 15+ |
| المنطقة الزمنية | `Asia/Baghdad` (UTC+3) — يُخزَّن الوقت بتوقيت UTC ويُعرض محلياً |
| المعرّف الثابت للطالب | `student_number` (فريد لكل مدرسة) |
| حالة المستند | مسودة للاعتماد |

> ملاحظات عامة:
> - كل الجداول تحتوي `id` (UUID أو BIGSERIAL)، و`created_at`، و`updated_at`.
> - الحذف الافتراضي **منطقي (Soft delete)** عبر `deleted_at`؛ لا حذف فعلي للسجلات التاريخية دون صلاحية وإجراء معتمد.
> - كل عملية حساسة تُسجَّل في `audit_log`.
> - الأوقات تُخزَّن في الخادم بتوقيت UTC (`timestamptz`)، ويُعتمد وقت الخادم لا وقت الهاتف.

## 10. ملاحظات تصميمية مبرَّرة
1. **`student_number` هو المعرّف** — لا يُعتمد على الاسم.
2. **وقت الخادم هو المرجع** — لا يُعتمد على ساعة الهاتف وحدها.
3. **قيدان لامركزان لمنع التكرار**: قيد منطقي (طالب/تاريخ/نوع) + قيد Idempotency (`client_uuid`).
4. **فصل الحضور عن محاولات التعرّف** لأغراض المراجعة والتدقيق.
5. **الدرجات والحضور لها جداول تدقيق مستقلة** إضافة إلى `audit_log` العام.
6. **قواعد مرنة في JSONB** لتقليل الحاجة لتعديل الكود عند تغيّر سياسة المدرسة.
7. **السمات فقط (لا صور)** افتراضياً، ومشفّرة، وقابلة للإلغاء دون حذف الملف المدرسي.
8. **Soft delete** للسجلات التاريخية مع منع الحذف الفعلي دون صلاحية وإجراء معتمد.
