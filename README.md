# نظام إدارة المدرسة الذكي

عرض فني وتنفيذي لمشروع نظام إدارة مدرسي متكامل:
تطبيق Android + نظام الحاسوب + التعرّف على الوجوه + الحضور والانصراف + إدارة الطلاب.

## حالة المشروع
مرحلة **التنفيذ الفعلي**: التطبيق يُبنى فعلياً (Flutter) ويعمل على Android، مع شاشات
الحضور بالتعرّف على الوجه، وملفات الطلاب، والصفوف والشعب، والدرجات، والتقارير،
والصلاحيات، وسجل العمليات. قاعدة بيانات SQLite محلية (Offline-first) جاهزة للربط
بـ PostgreSQL لاحقاً. المحرّك يعمل محلياً بالكامل (بلا إنترنت وبلا APIs مدفوعة).

| العنصر | الحالة |
|---|---|
| بناء APK (Android) | ✅ `flutter build apk` |
| تحليل الكود | ✅ `flutter analyze` نظيف |
| الاختبارات | ✅ 31 اختباراً ناجحاً |
| سطح مكتب Windows | ✅ الأهداف موجودة (يتطلب مضيف Windows للبناء) |
