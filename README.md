# نظام إدارة المدرسة الذكي

عرض فني وتنفيذي لمشروع نظام إدارة مدرسي متكامل:
تطبيق Android + نظام الحاسوب + التعرّف على الوجوه + الحضور والانصراف + إدارة الطلاب.

## حالة المشروع
مرحلة **التنفيذ الفعلي**: التطبيق يُبنى فعلياً (Flutter) ويعمل على Android، مع شاشات
الحضور بالتعرّف على الوجه، وملفات الطلاب، والصفوف والشعب، والدرجات، والتقارير،
والصلاحيات، وسجل العمليات. قاعدة بيانات SQLite محلية (Offline-first) جاهزة للربط
بـ PostgreSQL لاحقاً. المحرّك يعمل محلياً بالكامل (بلا إنترنت وبلا APIs مدفوعة).

| العنصر | الحالة |
|---|---|
| بناء APK (Android) | ✅ `flutter build apk --split-per-abi` |
| بناء سطح المكتب | ✅ `flutter build linux --release` (وهدف Windows جاهز) |
| تحليل الكود | ✅ `flutter analyze` نظيف |
| الاختبارات | ✅ 36 اختباراً ناجحاً |
| تعدد المدارس (المالك) | ✅ منصة المالك تُنشئ المدارس وتديرها |

## بناء برنامج الحاسوب (Windows)
Flutter لا يبني ملفات ويندوز (exe) إلا على ويندوز. لذلك:
- **على جهاز ويندوز:** شغّل `scripts/build_windows.bat` (يتطلب Flutter + Visual Studio 2022 مع
  workload «Desktop development with C++»). الناتج: `app/build/windows/x64/runner/Release/school_app.exe`.
- **عبر CI:** الـworkflow `.github/workflows/build-windows-desktop.yml` يبني على `windows-latest`
  ويرفع ملف `SmartSchool-Windows.zip` قابلاً للتنزيل (فك الضغط وشغّل `school_app.exe` مباشرة).
- بناء سطح المكتب من لينكس: `flutter build linux --release` (للتجربة والتحقق فقط).

## أول استخدام
عند أول تشغيل: تُنشأ حساب **المالك = مسؤول المنصة** (اسم المستخدم وكلمة المرور التي تدخلها)،
**دون** إنشاء مدرسة. من لوحة المالك يمكن إنشاء مدارس مستقلة (Multi-tenant) بمعزل تام للبيانات،
مع إنشاء حساب مدير لكل مدرسة تلقائياً. مدير المدرسة يدير كل ما يخص مدرسته: الصفوف والشعب،
الطلاب، المعلمين والمشرفين، البصمات، الغيابات، الدرجات، التقارير والإعدادات.

## لوحة التحكم (شبكة مربّعات)
واجهة رئيسية أنيقة بمربّعات حسب الصلاحية: شاشة الحضور، إدارة الطلاب، إدارة الصفوف،
بصمات الطلاب، إدارة المعلمين والمشرفين، الهيكل المدرسي، الدرجات والامتحانات،
الغيابات والتقارير، حقول ملف الطالب، سجل العمليات، الإعدادات.
